## 📋 Overview

Modern DevSecOps pipelines generate vast security reports that require manual triaging. This project automates the entire feedback loop:
1. Executes 4 parallel security scans across code, dependencies, infrastructure, and secrets.
2. Consolidates scan failures into a unified log.
3. Leverages **Google Gemini 1.5 Flash** to evaluate code issues and draft fix patches.
4. Pauses for **Admin Approval** before applying any changes.
5. Auto-commits patches to GitHub and triggers a verification build upon approval.

## 🛠️ Tools & Technologies

| Tool | Category | Role |
| :--- | :--- | :--- |
| **Jenkins** | Orchestration | Runs the CI/CD pipeline stages |
| **Trufflehog** | Secrets Scanning | Detects exposed credentials, tokens, and API keys |
| **SonarQube** | SAST | Static Code Analysis for quality gates and code smells |
| **Snyk** | SCA | Software Composition Analysis for dependency vulnerabilities |
| **Checkov** | IaC Scanning | Scans Docker, Terraform, and K8s configuration files |
| **Gemini 1.5 Flash**| Generative AI | Analyzes error output, synthesizes logs, and rewrites code |
